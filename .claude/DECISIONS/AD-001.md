# PROBLEM

QGuard Helix requires a scalable architecture capable of supporting:

* Discovery
* Migration
* Trust Fabric
* PQAuth
* Quantum Vault
* Real-time Telemetry

The architecture must remain maintainable as modules expand.

---

# OPTIONS CONSIDERED

Option A

Next.js Monolith

Pros

* Full-stack framework
* Mature ecosystem

Cons

* Additional complexity
* Unnecessary SSR requirements

---

Option B

React + Vite + Express

Pros

* Simple
* Fast development
* Clear boundaries
* Easy scaling

Cons

* Separate frontend/backend concerns

---

Option C

Microservices

Pros

* High scalability

Cons

* Operational complexity
* Premature optimization

---

# DECISION

Adopt:

Frontend

* React
* Vite
* TypeScript

Backend

* Express API

Database

* Supabase PostgreSQL

Realtime

* SSE

---

# RATIONALE

Provides:

* Clear separation of concerns
* Fast iteration
* Enterprise scalability
* Reduced operational burden

---

# CONSEQUENCES

Positive

* Easier maintenance
* Clear ownership boundaries

Negative

* Requires API discipline

---

# REASSESSMENT

Review when:

* User count exceeds architecture limits
* Telemetry volume exceeds current design
* Multi-region deployment becomes necessary
