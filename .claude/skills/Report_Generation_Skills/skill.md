# Purpose

This skill defines the standards, architecture, quality requirements, and best practices for generating all enterprise reports within the QGuard Helix Platform.

The objective is to ensure every report is:

• Professional
• Enterprise Grade
• Executive Friendly
• Technically Accurate
• Evidence Driven
• Auditor Ready
• Board Ready
• Consistent
• Explainable
• Actionable

Reports must support executive decision making while maintaining complete technical traceability.

---

# Core Principles

Every report must follow these principles:

✓ Accuracy over aesthetics

✓ Evidence over assumptions

✓ Explainability over complexity

✓ Executive readability

✓ Technical traceability

✓ Consistency across every section

✓ No duplicated findings

✓ No fabricated values

✓ No contradictory statements

✓ No unexplained metrics

---

# Report Philosophy

The report generator DOES NOT perform assessments.

It ONLY presents assessment results.

Never invent:

• Risk Scores

• Readiness Scores

• Migration Costs

• Recommendations

• Timelines

• Compliance Status

Everything must originate from validated assessment data.

# Executive Summary Standards

The Executive Summary should answer:

Where are we today?

How much risk exists?

What are the biggest problems?

What should we fix first?

How much will it cost?

How long will it take?

What decisions are required?

Never exceed one page.

---

# Report Validation

Before exporting the report perform automatic validation.

Verify:

✓ No duplicated findings

✓ No duplicated assets

✓ No duplicated recommendations

✓ No duplicated costs

✓ No contradictory statements

✓ Current and Target values are consistent

✓ Timeline matches migration waves

✓ Risk calculations are valid

✓ Costs equal formulas

✓ Charts match source data

✓ Tables match source data

✓ Recommendations align with findings

A QGuard Helix report should never look like a scanner output.

• Current posture

• Business risk

• Technical risk

• Recommended actions

• Migration strategy

• Investment required
