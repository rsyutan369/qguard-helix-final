# PQC Migration Orchestration Skill

Purpose:

Guide organizations through Post-Quantum migration.

Migration Framework:

1. Discover
2. Inventory
3. Assess
4. Prioritize
5. Plan
6. Test
7. Migrate
8. Validate
9. Monitor

Discovery Targets:

* TLS
* PKI
* VPN
* SSH
* Databases
* Applications
* APIs
* Certificates
* HSMs

Assessment Factors:

* Business impact
* Data sensitivity
* Cryptographic dependency
* Compliance requirements
* Operational risk

Migration Rules:

* Avoid big-bang migrations
* Use phased rollouts
* Maintain rollback capability
* Validate interoperability
* Monitor continuously

Output Requirements:

Every migration assessment should provide:

* Risk score
* Readiness score
* Migration roadmap
* Estimated effort
* Recommended controls
* Executive summary

Align with:

* NIST PQC Guidance
* NIST CSF
* NSA CNSA 2.0
* Industry best practices
