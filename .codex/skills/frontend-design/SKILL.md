# Frontend Design Skill

Purpose:

Build enterprise-grade user interfaces for Qguard Helix.

Requirements:

* Next.js App Router
* TypeScript
* Tailwind CSS
* Shadcn UI
* Framer Motion

Design Standards:

* Professional SaaS appearance
* Responsive design
* Accessibility support
* Dark mode support
* Light mode support
* Smooth animations

Preferred Components:

* Cards
* Data Tables
* Drawers
* Modals
* Command Menus
* Tabs
* Charts

Dashboard Standards:

* Clear KPI visibility
* Actionable workflows
* Enterprise-grade layouts
* Minimal clutter

Avoid:

* Excessive animations
* Poor contrast
* Unclear navigation
* Inconsistent spacing

Every page must include:

* Loading states
* Empty states
* Error states
* Success states

All UI must feel comparable to enterprise products such as:

* CrowdStrike
* Wiz
* Palo Alto
* Microsoft Defender
* Datadog
