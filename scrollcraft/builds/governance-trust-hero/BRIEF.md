## Implementation specification

Use the existing React/Vite stack and Geist Variable. Main files: `src/pages/_governance-trust-hero.tsx`, `src/pages/governance-trust-hero.css`, and the page import. A page-local 3D module owns geometry and lifecycle. Public fallback: `public/governance/trust-fabric-fallback.svg`.

Hero tokens: canvas #081217, surface #11252b, ink #f1f5ef, muted #a8bcb9, accent #b7e4d2, accent-ink #10231f. Champagne #c7b98f is a material detail. Text never uses gradients or outer glow. Two font families at most: existing Geist and system monospace for diagram labels.

Desktop: max-width 1440px, 56px gutters, 132px top padding including existing 64px navigation, two columns 46%/54%, minimum scene height 510px, 32px bottom breathing room. Heading clamp(56px,6.1vw,96px), weight 500, .98 line-height, -.065em tracking. Paragraph 17px/1.65 with 430px maximum measure. Primary and secondary actions minimum 48px height. Four capability buttons sit in one rail below the composition; the active item is marked by an inset line and descriptive copy. No invented asset totals, trust scores, compliance claims or telemetry.

Tablet: 32px gutters, reduced scene scale, 56px title, two-column capability rail. Below 760px: 22px gutters, stacked copy then scene, 52px title at 390px, 340px scene, 44px minimum targets, two-column rail. At 320px: title 44px and wrapped actions. No content is clipped to force a viewport lock.

3D: one dynamically imported Three.js renderer, capped DPR 1.5, perspective product lens, original bevelled geometry, directional studio lighting, no external texture. Four satellite platforms connect to a layered central trust anchor. A selected path and satellite correspond to actual capability descriptions. Continuous animation is limited to 30fps. Offscreen and hidden documents stop rendering. ResizeObserver fits the camera; native passive scroll updates a ref without React state per frame. Event listeners, observers, geometries, materials, renderer and animation frame are disposed on unmount. Context loss reveals a local fallback. Rendering errors cannot hide copy or controls.

Pause stops ambient, scroll and pointer motion. Capability selection continues to update the static scene. Reduced motion skips entrances, pointer movement, scroll interpolation and ambient animation and renders only on initialization, resize or selection. Static SVG fallback preserves the semantic diagram when WebGL is unavailable.
